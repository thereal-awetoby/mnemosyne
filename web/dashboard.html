      Step by step

      How it works

      Mnemosyne is an AI governor that decides in private, posts proof of every decision on NEAR before anything moves, and gives its helper agents keys that can report but never spend.

      The governor: the boss that never trades

      The governor decides how much each helper agent should look after. It does its reasoning inside a sealed chip (a TEE on NEAR AI Cloud), so nobody can see how it decided, not even whoever runs the server. Before using an answer, Mnemosyne checks the chip's signature and that the chip is genuine.

      Proof on NEAR before anything moves

      Every decision is written to the NEAR blockchain as a short fingerprint (a hash), linked to the decision before it. Anyone can check it, and it can never be changed. If that write fails, the cycle stops and nothing moves. That's the memory gate: no proof, no action.

      Four helpers that can't spend

      Each sub-agent has one job and its own safety limits. Its key can only write a report (act, pause or refuse) to NEAR; NEAR itself rejects anything else. When an order breaks a helper's own limit, it refuses, and that refusal is public too. A refusal means the safety system worked.

      Paid checks: ask the memory

      Anyone, person or AI agent, can pay a tiny fee (0.001 NEAR) to ask whether a planned action matches a mistake Mnemosyne has already learned from. No account or API key: the payment is the permission (the x402 standard). You get a yes or no, one line of advice and a receipt, never the private details.

      One cycle, step by step

      1. Read the state: how much each helper holds.
      2. Decide privately inside the sealed chip.
      3. Write proof to NEAR. If this fails, stop.
      4. Move money, only after step 3 (off in practice runs).
      5. Helpers report act, pause or refuse on NEAR.
      6. Publish the public record; the reasoning stays private.

      Words on this page

      NEAR
      A public blockchain: a shared record nobody can quietly change.
      Testnet
      NEAR's practice network. Tokens there have no real value.
      TEE / sealed chip
      Secure hardware that runs code so even the server owner can't read it.
      Hash / fingerprint / ID
      A short code that identifies data exactly, without revealing it.
      Units
      Simulated money the helpers manage. Mnemosyne never trades, so losses are a labelled simulation.

      What's real and what isn't

      • Real, on NEAR testnet: the proofs, the helpers' reports and refusals, the locked-down keys, and paid checks in wNEAR.
      • Simulated, and labelled: the helpers' money and losses. Mnemosyne doesn't trade.
      • Paying from another chain is a price quote only by default.
